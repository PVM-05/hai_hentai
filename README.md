# 🔥 Album Hải Hentai - HAI.EXE

Trang web bộ sưu tập album ảnh & meme Hải Hentai theo phong cách giao diện meme video player đặc trưng.

## 🌟 Tính năng chính
- **Giao diện meme chuẩn:** Thiết kế tối màu đặc trưng với các nút tập `#1`, `#2`, mã số tác phẩm (`CMT8-1945`, `GDJ-1945`), thống kê tương tác (Like, Dislike, Tim ❤️, Lượt xem 👁️).
- **Trình xem ảnh chuyên nghiệp:**
  - Chuyển đổi mượt mà giữa các tập.
  - Phím mũi tên Trái / Phải để chuyển tập nhanh.
  - Nhấp vào ảnh để phóng to toàn màn hình (Lightbox).
- **Thư viện Album (Gallery Grid):** Danh sách toàn bộ các tác phẩm với thumbnail, chất lượng (4K HD, 1080P), và tìm kiếm trực tiếp (live filter).
- **Deploy dễ dàng trên GitHub Pages:** Tệp tĩnh 100%, đường dẫn tương đối, không phụ thuộc thư viện ngoài.

## 🚀 Hướng dẫn kích hoạt GitHub Pages
1. Vào repository trên GitHub: `https://github.com/PVM-05/HAI.EXE`
2. Chọn tab **Settings** -> **Pages** (ở cột bên trái).
3. Tại mục **Build and deployment**:
   - Chọn **Source**: **GitHub Actions** (đã có file tự động `.github/workflows/deploy.yml`), hoặc chọn **Deploy from a branch** với nhánh `main` và thư mục `/ (root)`.
4. Trang web sẽ sẵn sàng tại: `https://pvm-05.github.io/HAI.EXE/`
